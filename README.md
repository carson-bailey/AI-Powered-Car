# Project Overview: Smart Garage Door & Interactive Car System

This project builds on an existing students work, but adds several new features and improvements. The main focus of my version is a smart garage door system that can automatically open and close when it detects our car approaching. In addition, the car itself has been enhanced with obstacle avoidance capabilities, allowing it to navigate around objects autonomously.

The goal of this project was to combine multiple subsystems including motor control, sensors, and automation into a single system that demonstrates real world smart technology concepts.

# Key Features

Automatic Garage Door Operation
- The garage door opens and closes automatically when the car is detected nearby, reducing the need for manual operation. This feature is controlled via motor actuation and    sensor input.

Interactive Car Obstacle Avoidance
- The smart car can detect obstacles using ultrasonic sensors and adjust its movement to avoid collisions. This ensures smooth navigation and demonstrates autonomous vehicle   behavior on a small scale.

Integrated Control System
- The car and garage system communicate and operate together, demonstrating the integration of multiple subsystems into a single functional unit.

Technologies Used

- Elegoo Smart Car Kit
- Arduino (2 boards)
- DC Motors
- Ultrasonic sensors
- VS Code for code management
- Arduino IDE for programming microcontrollers
- Teachable Machine dataset for camera input

# Challenges Encountered

Subsystem Integration
- Combining multiple subsystems (the car, sensors, and garage door) into a single functioning system was challenging due to timing and communication between components.

Arduino Coding Issues
- Finding the correct motor speeds and writing obstacle avoidance logic required ALOT of testing and calibration.

VS Code and Arduino IDE Integration
- Ensuring that code could run properly across both environments.
  
Mechanical Design Challenges
- Designing the garage and door to work reliably with the car.
